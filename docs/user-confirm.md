# 用户确认清单（交付时一次性执行）

> 这些项目必须在真机上由你完成——Agent 环境无法代劳（签名、物理按键、长测观感）。
> 建议顺序：先装上空壳 → 导入 1 款 ROM 跑通 → 再逐项确认。

## 一、安装（必做）

- [ ] 用签名工具（Sideloadly / AltStore / 自签证书）对 `build/MiniRetro-1.0-1-unsigned.ipa` 签名
- [ ] 真机安装成功，图标「小霸王模拟器」可启动
- [ ] 若签名工具报「无法安装未签名 ipa」→ 改用 `./Tools/build.sh --adhoc` 重新构建后再试
- [ ] 记录免费 Apple ID 到期日：安装日 + 7 天（到期需重签）

## 二、iPad 6 基础体验（基准真机，iPadOS 17.x）

- [ ] 横屏启动，游戏库界面完整显示（无黑边、无裁切）
- [ ] 导入 1 款 FC ROM（如 homebrew 游戏），进入游戏画面正常
- [ ] 虚拟按键位置在拇指自然覆盖范围内（不别扭、不挡画面）
- [ ] 声音正常，无明显延迟（按键 → 发声 <80ms 主观感受）
- [ ] 帧率：菜单 → 开启 FPS 显示，观察 ≥59fps
- [ ] 快进 4× 时画面不撕裂、声音不爆音
- [ ] 进后台再回前台，进度未丢失

## 三、当前系统 iPhone/iPad（iOS/iPadOS 26/27）

- [ ] 安装并启动，界面无布局错位
- [ ] 导入 + 运行 1 款 GBA ROM，画面比例正确（不拉伸）
- [ ] 刘海/灵动岛区域不遮挡按键
- [ ] 蓝牙手柄连接后全键可用（A/B/L/R/十字/Start/Select）
- [ ] 控制中心/来电打断后恢复正常

## 四、长测与稳定性

- [ ] 连续游玩 2 小时：无崩溃、无异常发热（温感可接受）、电量消耗合理
- [ ] 低电量模式下游玩 15 分钟：帧率 ≥55fps
- [ ] 杀 App 重开 3 次：即时存档/自动存档均能恢复
- [ ] 存档 → 退出 → 重启设备 → 再读档：成功
- [ ] 使用「文件」App 从 iCloud Drive 导入 ROM：成功

## 五、素材合规自查

- [ ] 确认所有导入的 ROM 均为自有备份或自由/homebrew 作品
- [ ] 确认不向他人分发本 App 与 ROM 的打包体（GPL core 合规定性见 README）
